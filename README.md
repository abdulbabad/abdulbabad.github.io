# Abdul B. Abad — Academic Website

Static site for GitHub Pages (no build step).

## Files
- `index.html` — the whole site (About, Research, Teaching, CV)
- `style.css` — styles
- `Abad_CV.pdf` — full CV (linked from the site)
- `images/cvpage-1.png` … `cvpage-3.png` — CV page previews shown in the CV section

## Updating
Replace a file with a new version of the same name (Add file → Upload files → Commit changes).
The site refreshes within a few minutes at https://abdulbabad.github.io
